# 方案 A · iOS 快速配置清单

> 专为 iPhone 用户设计，按顺序勾选，**30 分钟内**完成。  
> 与 [PWA 看板](./plan-b-pwa-dashboard.md) 配合使用效果最佳。

---

## 开始前：确认权限

打开 **设置**，逐项检查：

| 路径 | 要求 |
|------|------|
| 设置 → 通知 → **日历** | 允许通知 ✅、声音 ✅、横幅 ✅ |
| 设置 → 通知 → **快捷指令** | 允许通知 ✅ |
| 设置 → 隐私与安全性 → **定位服务** → 企业微信 | 使用 App 期间 ✅ |
| 设置 → 屏幕使用时间 → **勿扰模式** | 见下方「专注模式例外」 |

---

## 第一步：日历提醒（必做，约 15 分钟）

打开 **日历** App，新建 **7 个重复事件**：

### 操作模板（每个事件相同流程）

1. 点右上角 **＋**
2. 填标题、时间（见下表）
3. 点 **重复** → 选择 **每工作日**（或自定义：周一～周五）
4. 点 **提醒** → 添加两个：
   - **事件发生时**
   - **提前 5 分钟**
5. 点 **添加**

### 7 个事件清单

| # | 标题 | 时间 | 备注 |
|---|------|------|------|
| 1 | 🟢 上班打卡 · 第一次 | **08:30** | 还有 20 分钟 |
| 2 | 🟢 上班打卡 · 第二次 | **08:45** | 5 分钟后到点 |
| 3 | 🔴 上班打卡 · 超时兜底 | **08:52** | 已过 08:50，立即打！ |
| 4 | 🟡 下班打卡 · 第一次 | **18:10** | 18:15 后可打 |
| 5 | 🟡 下班打卡 · 第二次 | **18:25** | 请完成下班打卡 |
| 6 | 🔴 下班打卡 · 超时兜底 | **20:00** | 若还没打，马上打 |
| 7 | 📋 今日打卡审计 | **22:00** | 打开企业微信统计核对 |

### 收到提醒后做什么

```
日历响了 → 点通知 → 打开「企业微信打卡」快捷指令（第二步创建）
         → 在企业微信完成打卡 → 打开「全勤守护」点「我已打卡」
```

## 第二步：快捷指令 · 一键打开企业微信（约 5 分钟）

1. 打开 **快捷指令** App
2. 点 **＋** 新建
3. 命名：`企业微信打卡`
4. 点 **添加操作**，依次添加：

```
动作 1：打开 App
       → 搜索「打开 App」→ 选择「企业微信」

动作 2：显示通知（可选但推荐）
       → 搜索「显示通知」
       → 标题：打卡提醒
       → 正文：请在打卡页面完成上下班打卡
```

5. 点右上角 **完成**
6. **添加到主屏幕**：
   - 长按「企业微信打卡」→ 详情 → 添加到主屏幕
   - 选个醒目图标（建议绿色）

**以后：** 日历提醒 → 点桌面「企业微信打卡」→ 直达 App。

---

## 第三步：自动化 · 定时自动弹出（约 10 分钟，强烈推荐）

> iOS 自动化可在到点时自动打开企业微信，比只靠日历更可靠。

### 自动化 1：上班 08:45

1. 快捷指令 → 底部 **自动化** → **＋** → **创建个人自动化**
2. 选 **特定时间** → 08:45 → 重复：**每周** → 勾选周一～周五
3. 下一步，添加动作：

```
显示通知
  标题：⏰ 上班打卡
  正文：5 分钟后 08:50，请打开企业微信打卡

打开 App
  选择：企业微信
```

4. 下一步 → **关闭「运行前询问」** → 完成

### 自动化 2：下班 18:25

同上，时间改为 **18:25**，通知改为：

```
标题：⏰ 下班打卡
正文：请完成下班打卡（18:15 后可打）
```

### 自动化 3：日终审计 22:00

```
触发：22:00，周一～周五

动作：
  显示通知
    标题：📋 今日打卡审计
    正文：请打开企业微信「统计」，确认今天 2 次都正常
```

---

## 第四步：专注模式例外（若你用勿扰/专注）

**设置 → 专注模式 → [工作/勿扰] → 允许的通知**

- 添加 **日历**
- 添加 **快捷指令**

或设置 **定时**：

- 08:25 自动关闭专注模式
- 09:00 自动恢复
- 18:00 自动关闭
- 20:30 自动恢复

---

## 第五步：习惯绑定（零配置，效果最好）

把打卡绑进固定动作，比任何提醒都稳：

| 场景 | 动作链 |
|------|--------|
| **到公司** | 进门前/电梯里 → 先打卡 → 再开电脑 |
| **下班** | 关电脑前 / 起身离开时 → 先打卡 → 再收包 |
| **22:00** | 统计页扫一眼 → 有红色立刻补卡 |

**贴工位备忘：**

```
□ 08:50 前 — 上班打卡
□ 18:15 后 — 下班打卡  
□ 22:00 — 统计页核对
```

## 第六步：安装 PWA 看板（方案 B）

1. 用 Safari 打开全勤守护 PWA 地址（开发完成后提供）
2. 点底部分享按钮 **↑**
3. 选 **添加到主屏幕**
4. 命名：**全勤守护**

**每日闭环：**

```
企业微信打完卡 → 打开「全勤守护」→ 点「我已上班/下班打卡」
```

> iOS 上 PWA 后台通知能力有限，**日历 + 自动化仍是主提醒**，PWA 负责看板和确认记录。

## 常见问题（iOS）

| 问题 | 解决 |
|------|------|
| 日历没响 | 检查通知权限；是否开了静音/专注 |
| 自动化要手动确认 | 编辑自动化 → 关闭「运行前询问」 |
| 企业微信显示不在范围 | 打开打卡页等几秒，或走到 GLA Family 范围内 |
| PWA 通知收不到 | 正常，iOS 限制大；靠日历方案 A 为主 |
| 调休/请假 | 当天在日历里删除事件，或在 PWA 标记「今日休息」 |

## 与方案 B 的分工

| 职责 | 方案 A（iOS 日历/自动化） | 方案 B（PWA） |
|------|---------------------------|---------------|
| 到点提醒 | ✅ 主力 | ⚠️ 辅助（iOS 弱） |
| 一键打开企业微信 | ✅ 快捷指令 | — |
| 我已打卡确认 | — | ✅ |
| 全勤进度/热力图 | — | ✅ |
| 22:00 漏打警报 | ✅ 日历 | ✅ App 内检查 |

**结论：两个都开，全勤奖更稳。**
