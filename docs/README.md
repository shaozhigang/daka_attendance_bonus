# 企业微信全勤打卡方案文档

> 目标：零遗漏完成上下班打卡，保住每月 **1000 元**全勤奖。

## 背景

| 项目 | 说明 |
|------|------|
| 打卡工具 | 企业微信 · 上下班打卡 |
| 上班时间 | 08:50 |
| 下班时间 | 18:15 后 |
| 打卡地点 | GLA Family（需在打卡范围内） |
| 全勤规则 | 漏打 1 次即失去全勤奖 |
| 容错率 | **0** |

## 方案总览

本仓库采用 **「三层防护」** 策略，由两套互补方案组成：

```
┌──────────────────────────────────────────────────┐
│  Layer 3 · 兜底审计                               │
│  每晚 22:00 检查 → 漏打则红色警报 + 补卡指引       │
├──────────────────────────────────────────────────┤
│  Layer 2 · 可视化看板（方案 B）                    │
│  全勤进度 / 日历热力图 / 今日状态 / 连续天数       │
├──────────────────────────────────────────────────┤
│  Layer 1 · 智能提醒（方案 A + B）                  │
│  多层提醒 + 确认闭环 + 未确认升级                  │
└──────────────────────────────────────────────────┘
```

| 方案 | 名称 | 投入 | 文档 |
|------|------|------|------|
| **A** | 零开发配置（日历 + 快捷指令） | 0 天，今天可用 | [plan-a-zero-dev-setup.md](./plan-a-zero-dev-setup.md) |
| **A-iOS** | iPhone 快速配置清单（推荐） | 30 分钟 | [plan-a-ios-quickstart.md](./plan-a-ios-quickstart.md) |
| **B** | PWA 考勤看板 + 提醒 App | MVP 已搭建 | [plan-b-pwa-dashboard.md](./plan-b-pwa-dashboard.md) |

## 推荐使用顺序

1. **今天**：按 [iOS 快速配置清单](./plan-a-ios-quickstart.md) 配置日历提醒和快捷指令
2. **现在**：运行 `npm install && npm run dev`，Safari 打开后「添加到主屏幕」
3. **持续**：A 和 B 同时运行，互为备份

## 不建议的做法

- ❌ 自动脚本代打卡（违规，后果严重）
- ❌ 只靠补卡（次数有限，审批不一定过）
- ❌ 只设一个闹钟（静音/开会易漏）
- ❌ 月底才对账（发现漏打时已无法补救）
