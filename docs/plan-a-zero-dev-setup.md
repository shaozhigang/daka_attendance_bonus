# 方案 A：零开发配置指南

> 不写一行代码，今天就能部署的三层提醒 + 习惯绑定方案。

---

## 一、方案目标

| 目标 | 指标 |
|------|------|
| 降低漏打概率 | 从「偶尔漏」→「接近 0」 |
| 部署时间 | 30 分钟内完成全部配置 |
| 成本 | 零 |

---

## 二、提醒时间表（核心）

根据你的打卡规则（上班 08:50、下班 18:15 后），建议配置以下 **7 个提醒节点**：

| 时间 | 类型 | 提醒内容 | 目的 |
|------|------|----------|------|
| **08:30** | 第一次 | 还有 20 分钟上班打卡 | 提前预警 |
| **08:45** | 第二次 | 5 分钟后打卡，准备打开企业微信 | 临近提醒 |
| **08:52** | 兜底 | 已过 08:50，立即打卡！ | 超时补救 |
| **18:10** | 第一次 | 即将下班，记得 18:15 后打卡 | 提前预警 |
| **18:25** | 第二次 | 请完成下班打卡 | 临近提醒 |
| **20:00** | 兜底 | 若未下班打卡，立即处理 | 超时补救 |
| **22:00** | 审计 | 打开企业微信「统计」，核对今天 2 次打卡 | 日终确认 |

## 三、iOS 配置步骤

### 3.1 日历重复事件（必做）

1. 打开 **日历** App
2. 新建事件 → 标题：`🟢 企业微信 · 上班打卡（第一次提醒）`
3. 时间：**08:30**，重复：**每个工作日**
4. 提醒：**事件发生时** + **事件前 5 分钟**（双重提醒）
5. 同样方式创建以下事件：

| 标题 | 时间 | 重复 |
|------|------|------|
| 🟢 企业微信 · 上班打卡（第一次提醒） | 08:30 | 每个工作日 |
| 🟢 企业微信 · 上班打卡（第二次提醒） | 08:45 | 每个工作日 |
| 🔴 企业微信 · 上班打卡（超时兜底） | 08:52 | 每个工作日 |
| 🟡 企业微信 · 下班打卡（第一次提醒） | 18:10 | 每个工作日 |
| 🟡 企业微信 · 下班打卡（第二次提醒） | 18:25 | 每个工作日 |
| 🔴 企业微信 · 下班打卡（超时兜底） | 20:00 | 每个工作日 |
| 📋 企业微信 · 今日打卡审计 | 22:00 | 每个工作日 |

6. 确保日历通知权限已开启：**设置 → 通知 → 日历 → 允许通知**

### 3.2 快捷指令：一键跳转企业微信打卡（推荐）

1. 打开 **快捷指令** App
2. 新建快捷指令，命名：`企业微信打卡`
3. 添加动作：
   - **打开 App** → 选择「企业微信」
   - （可选）**等待** 2 秒
   - **显示通知**：「请在打卡页面完成打卡」
4. 添加到主屏幕：快捷指令详情 → 添加到主屏幕 → 自定义图标

**使用方式：** 收到日历提醒后，点击主屏幕「企业微信打卡」图标，直达 App。

### 3.3 自动化：定时弹窗（进阶）

1. 快捷指令 → **自动化** → **创建个人自动化**
2. 触发器：**特定时间** → 08:45 → 重复：每周 → 选择周一至周五
3. 添加动作：
   - **显示通知**：标题「上班打卡」，正文「5 分钟后到点，请打开企业微信打卡」
   - **打开 App**：企业微信
4. 关闭「运行前询问」
5. 同样为 18:25 创建下班自动化

### 3.4 专注模式例外（重要）

若你使用专注模式/勿扰模式：

- **设置 → 专注模式 → [你的模式] → 允许的通知**
- 将「日历」和「快捷指令」加入允许列表
- 或设置 **08:25–09:00** 和 **18:00–20:30** 自动关闭专注模式

## 四、Android 配置步骤

### 4.1 Google 日历 / 系统日历（必做）

1. 打开 **Google 日历** 或系统自带日历
2. 创建事件，参考 iOS 第三节的时间表
3. 每个事件设置 **2 个提醒**：
   - 事件发生时
   - 提前 5 分钟
4. 重复规则：**每周一 to 周五**
5. 确保通知权限：**设置 → 应用 → 日历 → 通知 → 开启**

### 4.2 Tasker 自动化（推荐，Android 专属）

若已安装 Tasker（或通过 MacroDroid 等替代）：

**Profile 1：上班打卡提醒**
```
触发：Time → 08:45, Mon-Fri
动作：
  1. Notify → 标题「上班打卡」正文「5 分钟后到点！」
  2. Launch App → 企业微信
  3. Wait 5 min
  4. Notify → 标题「立即打卡！」正文「已过 08:50，请马上打卡」
```

**Profile 2：下班打卡提醒**
```
触发：Time → 18:25, Mon-Fri
动作：
  1. Notify → 标题「下班打卡」
  2. Launch App → 企业微信
```

**Profile 3：日终审计**
```
触发：Time → 22:00, Mon-Fri
动作：
  1. Notify → 标题「今日打卡审计」正文「请打开企业微信统计页核对」
```

### 4.3 桌面 Widget 提醒（零成本替代）

- 使用 **TickTick**、**Todoist** 或系统待办
- 创建每日重复任务：「上班打卡 ✅」「下班打卡 ✅」
- 设为 **08:30 / 18:10** 提醒
- 完成后手动勾选，形成闭环

## 五、习惯绑定（零技术，效果最强）

技术提醒是辅助，**习惯绑定**才是根本。建议固定以下动作链：

### 5.1 上班链

```
到公司 → 进电梯/门禁 → 【先打卡】 → 再开电脑 → 再坐下
```

- 把「打卡」绑在「开电脑之前」，而不是「坐下之后」
- 手机放在桌面显眼位置，到公司第一件事拿手机

### 5.2 下班链

```
准备离开 → 【先打卡】 → 再收东西 → 再出门
```

- 18:15 后任意时刻可打，建议在「关电脑前」或「起身离开时」
- 不要等「出公司大门」再打（可能已离开打卡范围）

### 5.3 日终审计链

```
22:00 提醒 → 打开企业微信 → 统计 → 看今天是否有红色/未打卡
```

- 若发现漏打，**当晚**提交补卡申请，不要拖到第二天

## 六、企业微信内可检查的设置

在企业微信 App 内搜索或查看：

1. **打卡 → 设置 / 更多** — 是否有「打卡提醒」开关
2. **我 → 设置 → 新消息通知** — 确保通知全开
3. **统计** — 添加到常用或置顶，方便每天扫一眼

> 注：部分功能依赖企业管理员配置，若无则以外部提醒为主。

## 七、节假日与调休

| 场景 | 处理方式 |
|------|----------|
| 法定节假日 | 日历事件需手动跳过，或使用「中国节假日」订阅日历自动识别 |
| 调休上班（周末上班） | 当天手动增加提醒，或日历设为「自定义重复」 |
| 请假 | 无需打卡，可忽略当日提醒 |
| 出差/外出 | 使用「外出打卡」Tab，规则不同，需单独确认 |

**建议：** 订阅 **「中国法定节假日」** 日历（iOS/Android 均可搜索添加），与工作日提醒配合使用。

## 十、故障排查

| 问题 | 可能原因 | 解决 |
|------|----------|------|
| 没收到提醒 | 勿扰/专注模式、日历通知关闭 | 检查通知权限与专注模式例外 |
| 提醒了但没打 | 习惯未建立、提醒后未行动 | 强化习惯绑定 + 使用方案 B 确认闭环 |
| 在公司范围外 | 定位未刷新 | 打开企业微信打卡页，等「你已在打卡范围内」再点 |
| 补卡被拒 | 超过次数或理由不充分 | 以预防为主，补卡仅作最后手段 |
